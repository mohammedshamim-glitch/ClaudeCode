# Monkey Finance — YouTube Upload Skill

Upload a finished Monkey Finance episode to YouTube with full SEO metadata automatically applied.

---

## What This Skill Does

1. Downloads the finished video (named after the episode title, slugified) from the episode's Google Drive folder
2. Reads and parses `06-seo-metadata.txt` — extracts title, description, tags, and chapter timestamps
3. Uploads the video to YouTube via the Data API v3 (resumable upload)
4. Sets all metadata, category (Education), language (en-GB), and schedules for next Wednesday 4pm UK
5. Uploads thumbnail from `thumbnail` file in the episode folder
6. Posts pinned comment automatically
7. Returns the YouTube watch URL and Studio link

---

## Pipeline position

Stage 7 — runs after:
- ✅ Video assembled (`<episode-title-slug>.mp4` in Drive) — Stage 5b
- ✅ `06-seo-metadata.txt` in Drive — Stage 5a
- ✅ `thumbnail` file in Drive — generated by Sham in Grok

## Pre-flight Checklist — Verify Before Running

- [ ] `06-seo-metadata.txt` exists in the episode Drive folder
- [ ] `thumbnail` file exists in the episode Drive folder (PNG or JPG — named exactly `thumbnail`)
- [ ] Finished MP4 exists in the episode Drive folder (named after episode title slug)
- [ ] `youtube_refresh_token` is set in `token.json`
- [ ] **Channel verified** — run `GET /youtube/v3/channels?part=snippet&mine=true` and confirm it returns "Monkey See Money" before proceeding. If it returns anything else, stop and re-authenticate with `setup_youtube_auth.py`.

## Running the Upload

```bash
python3 /home/user/ClaudeCode/upload_youtube.py <episode_folder_id>
```

No `--privacy` flag needed — scheduling is automatic. The script auto-schedules for next Wednesday at 4pm UK time, minimum 2 days after upload.

**Skip-a-Wednesday:** To target the Wednesday after next, temporarily set `MIN_DAYS_BUFFER = 4` in `upload_youtube.py`, run, then reset to `2`.

## What Gets Set Automatically

| Field | Source |
|-------|--------|
| Title | Primary title from `06-seo-metadata.txt` |
| Description | Full description block + chapter timestamps |
| Tags | All tags from the SEO package (up to 500 chars) |
| Category | Education (ID 27) |
| Language | en-GB (audio + default) |
| Privacy | Scheduled — auto-publishes on target Wednesday at 4pm UK |
| Made for kids | No |
| Thumbnail | Uploaded automatically from `thumbnail` file in episode folder |
| Pinned comment | Posted automatically from `06-seo-metadata.txt` PINNED COMMENT section |

---

## Pinned Comment — Auto-Posted, Manual Pin Required

The script automatically posts the pinned comment after upload. **However:** pinned comments only work on public/unlisted videos — not on scheduled/private. 

**Manual step required:** On the day the video goes live, go to YouTube Studio → Comments → find the posted comment → click three dots → **Pin**. Do this within 60 minutes of going live.

If comment post returns 403, re-run auth with force-ssl scope:
```bash
python3 /home/user/ClaudeCode/setup_youtube_auth.py
```

## Error Handling

| Error | Fix |
|-------|-----|
| `youtube_refresh_token` missing | Run `setup_youtube_auth.py`, select Monkey See Money |
| Wrong channel authenticated | Re-run `setup_youtube_auth.py`, select Monkey See Money (not personal/Digital Fusion) |
| `06-seo-metadata.txt` not found | Run Stage 5a (SEO skill) first |
| Video MP4 not found | Run Stage 5b (video assembly) first |
| 403 on upload | Check channel permissions; re-authenticate |
| Title parse fails | Check PRIMARY section format in `06-seo-metadata.txt` — must have `Primary:` on its own line |
