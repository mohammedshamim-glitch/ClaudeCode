# SCENE-TYPES.md — Scene Classification & Prompt Formulas

## Why Scene Types Matter

Not all scenes are the same. A stat-reveal scene needs a completely different visual treatment from an emotional reaction scene. This file gives you the classification system and a prompt formula for each type — so every scene gets the right visual treatment.

---

## Step 1 — Classify the Scene

Read the narration text for the scene and assign it one of the 7 types below. Most scenes fall clearly into one type. If a scene spans two types, pick the dominant one.

| Type | What it covers | Typical monkey usage |
|---|---|---|
| **A — Hook / Brand** | Opening and closing scenes | Green suit monkey |
| **B — Stat Reveal** | A specific number, percentage, or data point lands | No monkey (let the number breathe) |
| **C — Concept Explain** | An abstract concept is defined or explained | No monkey, or monkey as guide |
| **D — Emotional Reaction** | The viewer is meant to feel something — shock, relief, realisation | Monkey |
| **E — Comparison / Choice** | Two options, strategies, or outcomes are contrasted | No monkey |
| **F — Action Steps** | Practical things the viewer should do | No monkey |
| **G — Narrative / Story** | A scenario or story is being told (e.g. "Picture this...") | Monkey or no monkey |

---

## Prompt Formulas by Scene Type

Each formula is a starting point. Adapt to the specific narration content — these are structures, not scripts.

---

### Type A — Hook / Brand
**Used for:** Scene 01 (opening hook) and the final scene (CTA/sign-off)
**Monkey:** Green suit monkey, always

**Formula:**
```
2D colourful whiteboard animation style. Clean white background. 
A confident monkey in a bright green suit [position and action — e.g. stands on the right, 
arms wide open / points directly at the viewer]. On the [left/centre] of the canvas, 
[main headline text] written in bold [red/black] hand-drawn marker, [size description]. 
[Secondary text if any] in slightly smaller [colour] marker below. 
[Any supporting visual element — starburst, arrow, underline]. 
The overall energy is [urgent / warm and inviting / exciting]. 
Bold colourful hand-drawn illustration, 16:9 widescreen aspect ratio, landscape composition.
```

---

### Type B — Stat Reveal
**Used for:** Any scene where a specific number, percentage, or data point is the centrepiece
**Monkey:** None — let the number command the frame

**Formula:**
```
2D colourful whiteboard animation style. Clean white background. 
[The stat] written in massive bold [red/black] hand-drawn marker, dominating [position in frame]. 
[Underlined once/twice / surrounded by a bold marker border / followed by a short label]. 
[Secondary stat or context text] in slightly smaller marker below or beside it. 
[Supporting visual element — bar chart / warning triangle / explosion starburst / threshold line — 
in [colour], reinforcing the scale or impact of the number]. 
No character. The number owns the frame. 
Bold colourful hand-drawn illustration, 16:9 widescreen aspect ratio, landscape composition.
```

---

### Type C — Concept Explain
**Used for:** Defining a term, explaining a mechanism, introducing a framework
**Monkey:** Optional monkey if the concept needs a "guide" — otherwise no monkey

**Formula:**
```
2D colourful whiteboard animation style. Clean white background. 
A hand-drawn [diagram type — e.g. simple diagram / flow chart / two-box layout / equation] 
illustrating [the concept]. [Describe the visual elements — boxes, labels, arrows, icons] 
drawn in [colour] marker. [Key term or label] written in bold [colour] marker at [position]. 
[If a monkey is present:] A monkey on the [right/left], [expression], [action — e.g. 
pointing at the diagram / holding a marker as if explaining]. 
[Dominant colours and their roles in this scene]. 
Bold colourful hand-drawn illustration, 16:9 widescreen aspect ratio, landscape composition.
```

---

### Type D — Emotional Reaction
**Used for:** Peak emotional moments — the horror reveal, the "aha" moment, the realisation
**Monkey:** Monkey — the emotion must be unmistakable

**Formula:**
```
2D colourful whiteboard animation style. Clean white background. 
A monkey [position in frame — e.g. centre-left / right side], 
[specific expression description — e.g. hands flying to head in shock, mouth wide open / 
arms crossed, one eyebrow raised, dismissive / pointing forward, eyes wide, mouth forming an O]. 
[What the monkey is reacting to — e.g. a thought bubble above their head reading "..." / 
a large [red/black] hand-drawn text appearing to their [left/right] reading "..."]. 
[Any supporting visual element that reinforces the emotion]. 
[Colour accents — red for negative reactions, green for positive]. 
Bold colourful hand-drawn illustration, 16:9 widescreen aspect ratio, landscape composition.
```

---

### Type E — Comparison / Choice
**Used for:** Before/after, old vs new, two strategies, two outcomes
**Monkey:** None — the comparison IS the visual

**Formula:**
```
2D colourful whiteboard animation style. Clean white background. 
[Two-zone composition — describe the split clearly, e.g. split-screen / two forking paths / 
two columns / before-and-after boxes]. 
Left side: [Label in grey/red, struck through with X if it's the wrong/old option] 
showing [description of the wrong/old thing]. 
Right side: [Label in green, with a bold checkmark if it's the correct/new option] 
showing [description of the correct/new thing]. 
[Dividing element — a bold vertical line / fork in the road / arrow pointing right]. 
[Title text above or below if narration references it] in bold black marker. 
Bold colourful hand-drawn illustration, 16:9 widescreen aspect ratio, landscape composition.
```

---

### Type F — Action Steps
**Used for:** Practical "here's what to do" moments — numbered steps, checklists
**Monkey:** None — keep it clean and actionable

**Formula:**
```
2D colourful whiteboard animation style. Clean white background. 
A hand-drawn [checklist / numbered list / step-by-step flow] with [N] items. 
Each item is a hand-drawn checkbox or number in black marker, followed by [brief label text]. 
[One item highlighted in green / bold — the one being focused on in this scene]. 
[Any supporting visual — e.g. a simple icon beside each item / a progress arrow]. 
[If a stat appears in this scene, it is written beside the relevant step in bold red marker]. 
Clean, spacious composition — no clutter. 
Bold colourful hand-drawn illustration, 16:9 widescreen aspect ratio, landscape composition.
```

---

### Type G — Narrative / Story
**Used for:** Storytelling scenes — "picture this", relatable scenarios, examples
**Monkey:** Plain monkey when the scene benefits from a "protagonist" — otherwise no monkey

**Formula:**
```
2D colourful whiteboard animation style. Clean white background. 
[Scene setting — drawn simply as 2D icons or props, not a full environment]. 
[Key visual narrative element — e.g. a timeline with a figure adding money at each tick / 
a simple house with a price tag / a pension pot growing then cracking]. 
[Label text written in marker at key points in the narrative visual]. 
[If monkey is present:] A monkey [position], [expression reflecting the mood of the story — 
proud / worried / confused], [action — holding a coin / looking at a timeline]. 
[Colour accents reflecting the emotional direction of the story — green while things are good, 
red when the problem hits]. 
Bold colourful hand-drawn illustration, 16:9 widescreen aspect ratio, landscape composition.
```

## Scene Sequencing — Visual Variety Rules

When reviewing the full prompt set, check that adjacent scenes don't share the same:
- Composition type (e.g. two consecutive split-screens)
- Dominant colour (e.g. two consecutive all-red stat scenes)
- Monkey usage (e.g. three consecutive scenes with a monkey)

If two adjacent scenes share any of the above, vary one of them. Visual rhythm matters.

**Ideal scene rhythm pattern (example across 10 scenes):**
```
Type A (green suit)  →  Type B (stat)  →  Type G (story, no monkey)  →  
Type D (monkey, reaction)  →  Type C (diagram)  →  Type B (stat)  →  
Type G (story)  →  Type D (monkey)  →  Type F (action steps)  →  Type A (green suit)
```

This rhythm keeps the viewer visually engaged — alternating between data-heavy and character-led scenes.
