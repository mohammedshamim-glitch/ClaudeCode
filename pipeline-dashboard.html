⚠️ Critical Rules

🖼️ Image Naming

Files must be named N-description.jpg where N is the flat scene number (1, 2, 3…). Never section-based like 21 for scene 2.1 — breaks sort order.

⏱️ aeneas Only

Forced alignment is mandatory. Proportional and Whisper fallbacks are banned — they can drift up to 6 seconds. If aeneas fails, fix the environment. Never downgrade.

📺 Channel Check

Before every upload, verify the channel returns "Monkey See Money". If it shows Digital Fusion or personal account, re-run setup_youtube_auth.py.

🔑 TTS Key

The gemini_tts_api_key is for TTS only. Other Gemini calls use gemini_api_key. Never mix them.

🐒 Monkey Rules

Monkey in ~25% of scenes. Always mid-action with a prop. Never just standing. Never specify suit colour. Never replaces a named character — accompanies only.

📌 Pin Timing

Pinned comment must be posted manually in Studio within 60 minutes of going live. Scheduled videos can't receive API comments until published.
