⚠️ Critical Rules

🖼️ Image Naming

Files must be named N-description.jpg where N is the flat scene number (1, 2, 3…). Never use section-based names like 21 for scene 2.1 — they break sort order and put images in the wrong order.

⏱️ Timings — aeneas Only

Forced alignment via aeneas is mandatory. Proportional and Whisper fallbacks are banned for final output — they can drift up to 6 seconds. If aeneas fails, fix the environment. Never silently downgrade.

📺 Channel Check

Before every upload, verify the authenticated channel returns "Monkey See Money". If it returns anything else (Digital Fusion, personal account), stop and re-authenticate with setup_youtube_auth.py.

🔑 TTS API Key

The gemini_tts_api_key is used for TTS only — never for other Gemini API calls. Other Gemini calls use gemini_api_key.

🗂️ SEO File Format

The 06-seo-metadata.txt section name must be TITLES with Primary: on its own line and the title on the next. Wrong format causes upload failure.

🐒 Monkey Rules

Monkey appears in ~25% of scenes. Must always be mid-action with a prop — never just standing. Never specify suit colour. Never replace a named character — monkey accompanies, not substitutes.

📌 Pinned Comment Timing

Scheduled videos can't receive pinned comments via API until live. Post manually in Studio within 60 minutes of going live, then pin (3 dots → Pin).

📁 Drive Files

All assets live in Google Drive — never local. Use known folder IDs directly. Name thumbnail thumbnail so upload_youtube.py finds it automatically.
